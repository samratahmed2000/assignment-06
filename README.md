# 💪 FitLog

A modern workout tracking web application built with Next.js. Browse workouts, view detailed exercise information, save workouts for later, and build a personalized plan for today's workout.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- Context API

## Key Features

- Browse a responsive workout library with workout details and stats.
- View detailed information including equipment, difficulty, sets, reps, calories, and instructions.
- Add workouts to Today's Plan with a maximum limit of five workouts.
- Save workouts for later and manage them from the My Plan page.
- Track exercises, total workout minutes, and calories with live metrics.
- Sort workouts by duration, calories, or rating.
- Mark completed workouts as done or remove them from the plan.
- Responsive design for mobile, tablet, and desktop devices.

## Key Features - Details

### 1. Add to Today's Plan

Users can add their preferred workouts to **Today's Plan** and build a personalized workout list. The plan is limited to five exercises and updates the plan counter and workout metrics automatically.

### 2. Save for Later

Users can save workouts they are interested in for later. Saved workouts are organized in the **Saved** tab on the My Plan page for easy access.

### 3. Remove Workout

Users can remove any workout from **Today's Plan** or **Saved** at any time. The related counters and workout statistics update automatically after removal.

### 4. Mark as Done

Users can mark a planned workout as **Done** after completing it. A confirmation toast is displayed and the completed workout is removed from the active plan.

### 5. Sort Workouts

Users can sort the workout library by **Duration, Calories, or Rating**, making it easier to find workouts based on their preferred criteria.
